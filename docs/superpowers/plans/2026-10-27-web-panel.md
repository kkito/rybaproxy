# Web 管理面板完善 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 B 档 spec 把管理面板接上真实数据并补齐 API，单元测试全覆盖。

**Architecture:** 原地扩展 `src/web/web.c`（拆出 `src/web/web_api.c` + `src/web/web_page.h`）；DB 层新增聚合查询；前端 JS 重写为 fetch 真实 API + 5s 轮询。

**Tech Stack:** C11, CivetWeb, cJSON, SQLite3, cmocka, 原生 JS（无构建）

## Global Constraints

- B 档范围：完整对齐 web-api.md，不做 SSE/Auth（轮询代替 SSE）。
- 上游 test 做真实 TCP 探测（非阻塞 connect + 3s 超时），不可达返回 200 + reachable=false。
- Heatmap/今日流量唯一口径：`GET /api/stats/daily?days=30`（SQLite 按天聚合）。
- from/to 统一为 unix ms；query 兼容 `?id=` 旧式。
- 统一信封 `{ok:true,data}` / `{ok:false,error:{code,message}}`；分页 `{data,total,limit,offset}`。
- CSS 花园午后风格不动，只重写 JS；YAGNI，不引入前端构建。

- [ ] **Step 2: db.h 声明 + db.c 实现（最小可用）**

```c
/* include/rybaproxy/db.h append */
int db_query_sessions(const char *client, const char *target, int upstream_id, int limit, int offset, char *buf, size_t bufsz, int *out_total);
int db_stats_summary(long long from_ms, long long to_ms, char *buf, size_t bufsz);
int db_stats_daily(int days, char *buf, size_t bufsz);
int db_stats_top(const char *by, int limit, long long from_ms, long long to_ms, char *buf, size_t bufsz);

int db_settings_set(const char *key, const char *value);
```

实现要点（db.c 内，共用一个 `db_escape` 转义 `"` 和 `\`）：
- `db_query_sessions`: 两条 SQL，先 `SELECT COUNT(*)`（同 WHERE），再分页查；WHERE 拼接：client 用 `client_ip LIKE '%c%'`，target 用 `target_host LIKE`，upstream 用 `upstream_id=?`（upstream_id<0 表示不过滤）；limit 夹紧 1..1000，offset>=0；输出完整 `{"data":[...],"total":N,"limit":L,"offset":O}`。
- `db_stats_summary`: `SELECT COUNT(*),COALESCE(SUM(bytes_up),0),COALESCE(SUM(bytes_down),0),COALESCE(SUM(status!=0),0) FROM sessions WHERE (?<=0 OR started_at>=?) AND (?<=0 OR started_at<=?)`，from/to<=0 表示不过滤。
- `db_stats_daily`: `SELECT date(started_at/1000,'unixepoch') d,COUNT(*),SUM(bytes_up),SUM(bytes_down),SUM(status!=0) FROM sessions WHERE started_at >= (strftime('%s','now',?||' days')*1000) GROUP BY d ORDER BY d`（`?` 为 `-days` 字符串如 `'-30 days'`）。
- `db_stats_top`: by=="client" 则 `GROUP BY client_ip`，否则 `GROUP BY target_host`，`ORDER BY SUM(bytes_up+bytes_down) DESC LIMIT ?`。
- settings: `SELECT key,value FROM settings` 组装对象；set 用 `INSERT OR REPLACE`。
- 保留旧 `db_get_recent_sessions`（改为调 `db_query_sessions(NULL,NULL,-1,limit,0,...)` 后提取 data 数组？不——保持原样避免回归，新函数独立实现）。
